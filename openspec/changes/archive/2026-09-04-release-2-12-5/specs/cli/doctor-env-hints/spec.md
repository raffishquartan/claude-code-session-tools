## Purpose

Defines what `ccst doctor`'s environment-variable checks must tell the user when a check does not
pass, so a WARN/FAIL result is actionable on its own without consulting other documentation.

## ADDED Requirements

### Requirement: Environment-variable checks may carry a fix hint
`ccst doctor`'s environment-variable directory check (`ENV:<var>`) SHALL accept an optional hint
string. When present, the hint is appended to the check's reason on WARN (variable unset) and FAIL
(variable set but not an existing directory) outcomes. On OK (variable set and pointing at an
existing directory), the hint is never shown - once the value is valid there is nothing left to
point the user at.

#### Scenario: Unset session-root variable shows a hint
- **WHEN** `CLAUDE_SESSION_TOOLS_REPO_ROOT` is unset and a hint is configured for it
- **THEN** the `ENV:CLAUDE_SESSION_TOOLS_REPO_ROOT` check reports WARN with a reason that includes
  both "not set" and the hint text

#### Scenario: Set-but-missing session-root variable shows a hint
- **WHEN** `CLAUDE_SESSION_TOOLS_REPO_ROOT` is set to a path that does not exist as a directory,
  and a hint is configured for it
- **THEN** the check reports FAIL with a reason that includes both the missing-directory message
  and the hint text

#### Scenario: Valid session-root variable omits the hint
- **WHEN** `CLAUDE_SESSION_TOOLS_REPO_ROOT` is set to an existing directory
- **THEN** the check reports OK with just the resolved path - the hint text does not appear

### Requirement: The two session-root checks carry a concrete fix hint
`ccst doctor`'s checks for `CLAUDE_SESSION_TOOLS_REPO_ROOT` and `CLAUDE_SESSION_TOOLS_PROJ_ROOT`
SHALL each use a hint naming the exact `export` line to add and the file to add it to
(`~/.shellrc.d/env.sh`), and SHALL state that this must not be `~/.shellrc.d/ccl.sh`, since that
file is fully regenerated by `ccst shell install --apply` and silently drops hand-edits.

#### Scenario: Hint names the correct file
- **WHEN** either session-root check is WARN or FAIL
- **THEN** its reason names `~/.shellrc.d/env.sh` as the file to add the `export` line to, and
  explicitly warns against putting it in `~/.shellrc.d/ccl.sh`
